# C++ Module 08 — Templated Containers & Iterators

This repository contains **Module 08** of the 42 C++ Piscine.  
It explores advanced **template programming**, working with **standard containers (STL)**, **iterators**, and creating **custom templated classes** that interact with the STL.

---

## Objectives

- Learn and apply **C++ templates**
- Work with **STL containers**: `vector`, `list`, `deque`, etc.
- Use **iterators**, `begin()` / `end()` / `rbegin()` / `rend()`
- Implement **search functions** using templates
- Handle **generic code** that works with multiple container types
- Discover the power of the Standard Template Library (STL)

---

## Key Concepts

- Function templates
- Class templates
- Iterators (standard & reverse)
- Exception handling in templated contexts
- Generic programming principles
- Template specialization (optional)
